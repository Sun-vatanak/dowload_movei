# Media Downloader Dashboard

A small desktop application built with PyQt6 and yt-dlp for downloading video or audio from public URLs.

## Features

- Download media from a URL
- Choose between best quality, MP4, MKV, or audio-only output
- Select where files are saved
- Real-time progress updates shown in the app
- Runs downloads in a background thread so the UI remains responsive

## Setup

```bash
cd /Users/vatanak/Documents/NU
.venv/bin/python -m pip install -r movie_downloader_app/requirements.txt
```

## Run

```bash
cd /Users/vatanak/Documents/NU
.venv/bin/python -m movie_downloader_app.main
```

This project is meant as a desktop starter and can be expanded with playlist support, queue management, or a more advanced dashboard layout.
